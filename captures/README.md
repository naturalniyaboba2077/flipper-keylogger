# Captures

Tree written by the VPS receiver and synced **every minute**:

```text
captures/{host}/{user}/{YYYY-MM-DD}/{HH-MM}.txt
```

- Times are **UTC**
- One file per user per calendar minute (appended if more packets arrive in the same minute)
- `#KL|v=2|host=...|user=...|lang=0419|tag=ru-RU` packets include keyboard language

Do not edit by hand unless you know why.
